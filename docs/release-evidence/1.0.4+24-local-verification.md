# Room of Days 1.0.4+24 — superseded identity note

Apple already contains Version 1.0.4, Build 24 from Codemagic build 34,
produced August 19, 2026 from source commit
`ade02ef8b58c421ae25ba6f7ac3379d8279abcf3`.

The later August 21 local verification at commit `2f75ac2` initially kept the
same build number because the App Store Connect high-water state was not yet
available locally. That verification covered the final sound system, Goals
take-back and reselection, Planning Ember discoverability, and narrow-layout
repair, but it cannot attest the older Build 24 binary already on Apple.

Build 24 is therefore superseded and must not be attached to the App Store
Version 1.0.4 draft. The exact final candidate advances to `1.0.4+25`; its
verification record is
[`1.0.4+25-local-verification.md`](1.0.4+25-local-verification.md).

Android remains deliberately separate on its frozen `1.0.2+20` candidate.
