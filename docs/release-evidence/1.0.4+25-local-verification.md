# Room of Days 1.0.4+25 — local release verification

Prepared August 21, 2026 from the final Build 25 candidate working tree on
`release/room-of-days-1.0.4`. The final source commit, signed IPA hash, and
Codemagic receipt will be recorded only after the candidate is committed and
the native workflow has run.

Build 23 is processed in TestFlight and remains the internal fallback. Apple
also contains Build 24 from older commit `ade02ef`, but that binary predates the
final sound and quest-management work and is explicitly superseded. Build 25
is the intended candidate for the App Store Version 1.0.4 draft.

## Included release scope

- Goals are again something the person controls: a taken quest can be taken
  back, reselected, or moved to another weekly day without losing its usable
  path through the app.
- The time-bound Planning Ember is reachable before the lazily built quest
  list, rather than being hidden behind it.
- The Journal’s large-text heading and bookplate remain usable at a 320-pixel
  width with 2× text scaling.
- Everyday taps use the approved crisp five-take X voice, so repeated actions
  retain a small, natural variation without turning into a random set of
  unrelated sounds.
- A bounded Paired Return may answer a deliberate run of everyday actions as
  the authored D5 → A5 → E5 → D5 gesture. It can happen once per stable screen,
  has a 90-second global cooldown, aborts on rapid tapping, never catches up
  afterward, and is interrupted by completion feedback.
- Completion keeps its own answering detent rather than being confused with an
  ordinary click. Screen changes clear an in-progress return; reduced and
  assistive interaction paths continue to receive one appropriate response.
- The existing Daybook, optional School lane, calendar views, stable day
  interaction, Then & Now journal rotation, manual locations and map handoff,
  Room Guide, and gentler streak freezes remain in the candidate.

Looping ambience remains deliberately outside Build 25. It needs a separate
opt-in product decision, licensed source, and long-session physical audition.
Android publication remains deferred; this record is not evidence of a new
Android candidate or Android store release.

- `flutter analyze`: no issues.
- `flutter test`: all 739 tests passed in 2 minutes 3 seconds.
- `dart run tool/verify_store_submission.dart --ios-only`: passed; the store
  fields, URLs, artwork, privacy/export records, release notes, and
  `1.0.4+25` identity agree.
- The Paired Return authoring regression passed all 7 tests, and the sonic
  system validator reported 0 errors and 0 warnings.
- The production WebAssembly build completed. Its offline package contains 232
  current files: 26.3 MiB in the startup set and 10.2 MiB deferred.
- The suite includes direct coverage for quest take-back/reselect behavior and
  weekly-day changes, Planning Ember discoverability, the Journal 320px/2×
  layout, and the everyday/return/completion sound rules.
- The broader suite also covers release identity, persistence, routing,
  accessibility activation, narrow layouts, store artwork, privacy, and the
  interaction router’s repeat, cancellation, and screen-transition behavior.
- The approved Paired Return was heard and accepted on the physical iPhone
  gate: iPhone 17 built-in speaker, full volume, quiet room; discovery, rapid
  plainness, and completion interruption reels were all completed naturally.
  The recorded verdict is `ready` in
  `design/audits/2026-08-20/room-paired-return-phone-gate-v1/LISTENING-RESULT.md`.

The Codemagic workflow emits `release-evidence.txt` beside the IPA with the
final source commit, binary hash, bundle identity, version/build, signing
identity, profile, SDK, and associated-domain checks. That receipt is the
authority for the signed artifact. Upload, TestFlight processing, App Review,
web publication, Android publication, and public catalog availability are
distinct states.
