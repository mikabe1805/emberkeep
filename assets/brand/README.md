# Morrowloom brand assets

- `design/source-assets/runtime-originals/assets/brand/morrowloom-icon-source.png`
  is the owner-approved canonical square artwork.
- `design/source-assets/runtime-originals/assets/brand/morrowloom-tapestry-room.png`
  is the full-resolution room-integration cutout derived from that source.
- `design/source-assets/runtime-originals/assets/brand/morrow-tapestry-wide.png`
  is the owner-directed full-resolution 3:1 Quest HUD derivative,
  generated with the built-in image-generation workflow on 2026-07-29 from:
  - the canonical square artwork; and
  - the selected option-1 Quest-page mock
    (`exec-b7c76b82-7fb7-4d6d-b678-ff8e9e8a04b4.png`).

The wide derivative preserves the same literal woven-dawn subject, rod,
faceted brass/copper construction, plum wool, gold sunrise, and mountain
grammar. It contains no copy or UI controls. Quest Desk customization may
change the surrounding frame and textile rail, but must not recolor the
finished brand artwork itself.

The app bundles the phone-sized WebP derivatives in this folder:
`morrowloom-icon-runtime-v2.webp`, `morrowloom-tapestry-room-v2.webp`, and
`morrow-tapestry-wide-v2.webp`. The archive is canonical; these runtime files
are intentionally replaceable delivery assets.
